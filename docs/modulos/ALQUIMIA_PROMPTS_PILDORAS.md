# Alquimia: prompts para el arte de las píldoras nuevas

Referencia de estilo: `art/alquimia_pildoras_actuales.png`. Entrega: PNG de **128×128** con fondo transparente, o sobre fondo liso
(blanco o magenta) para recortarlo después. Una píldora por imagen.

## Estilo común (pegar antes de cada prompt)

```
Game item icon, single round alchemy pill, glossy sphere seen slightly from above, painterly hand-painted style like the
other pills of the set, thick dark outline, soft rim light from the top left, small golden cloud-swirl ornament wrapped
around the lower part of the pill, a simple emblem carved or glowing on the front, centered, fills about 80% of the frame,
plain flat background, no text, no shadow on the ground, no frame, Chinese xianxia / wuxia fantasy, 128x128 icon
```
