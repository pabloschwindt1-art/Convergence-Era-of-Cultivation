# Integración con los sistemas del juego

**Principio n.º 1 (decisión del usuario):** el mod se integra con TODOS los sistemas existentes de RimWorld y sus DLC.
No inventamos sistemas paralelos: el cultivo se conecta con lo que el juego ya tiene. Cada módulo nuevo revisa esta
tabla. Estado: ✅ hecho · 🔄 en curso · ⬜ pendiente.

## Reglas para los agentes
- Antes de crear un sistema nuevo, buscar el sistema vanilla equivalente (ilspycmd, defs de Data/) y engancharse a él.
- Si una DLC tiene un sistema relacionado, integrarlo con carpeta condicional `Mods/<DLC>` o `MayRequire`.
- Actualizar el estado de esta tabla al terminar cada hito.
